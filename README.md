
# 🛒 Carrito de Compras en React

Este proyecto es una **aplicación de práctica** desarrollada con **React + Vite**.  
Simula un **carrito de compras** donde se pueden visualizar productos, agregarlos al carrito, calcular el total y realizar un flujo básico de pago.  

---

## 🚀 Características principales
- 📦 Listado de productos dinámico.
- ➕➖ Agregar y quitar productos del carrito.
- 💰 Cálculo automático del total de la compra.
- 🔐 Contextos de autenticación y carrito (AuthContext, CartContext, ProductsContext).
- 🧾 Simulación de proceso de pago.
- 🎨 Estilos con **CSS y Bootstrap** para un diseño responsivo.

---

## 🛠️ Tecnologías utilizadas
- [React](https://react.dev/)  
- [Vite](https://vitejs.dev/)  
- [Bootstrap](https://getbootstrap.com/)  
- Context API de React  
- GitHub Pages para despliegue
